# Библиотека промптов

Командные промпты с карточками, версиями и тест-кейсами. Учебный проект к уроку PEd01 курса «Промпт-инжиниринг» (Zerocoder).

## Каталог

| Промпт | Версия | Владелец | Теги | Назначение |
|---|---|---|---|---|
| [RAG Answer](prompts/rag-answer/card.md) | 1.0.0 | @yagitpa | rag, knowledge-base, support, ru | Ответ по найденным фрагментам: полный, частичный или отказ, со ссылкой на источник |

## Как устроена папка промпта

```
prompts/<имя>/
  card.md        карточка: цель, переменные, пример, тест-кейсы, правила
  system.md      системный промпт с переменными {{ИМЯ}}
  user.md        шаблон пользовательского сообщения
  CHANGELOG.md   история версий
  history/       прежние редакции для сравнения
```

## Как добавить или изменить промпт

1. Создать ветку, внести правку.
2. Поднять версию по правилам в карточке и дописать `CHANGELOG.md`.
3. Прогнать тест-кейсы из карточки и приложить результат к pull request.
4. Отправить на ревью владельцу промпта.
